# homebrew-smart-agents-memory

The Homebrew tap of [Smart Agents Memory](https://github.com/lindoelio/smart-agents-memory).

## Install

```bash
brew install lindoelio/smart-agents-memory/smart-agents-memory
```

Then wire the tools to your memory:

```bash
smart-agents-memory install
```

## How this repository is maintained

The formula is **not** edited by hand. The release pipeline of the product
rewrites it with the version, the URLs and the checksums of the new release,
and pushes it here. The same version as the release, always.

The placeholders in the formula are the checksums of the assets that do not
exist yet: the first release replaces them.
